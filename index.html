surveillance-upload

把自家监控录像备份到自己的 Google Drive。

这是一个只给自己用的工具，跑在我家里的一台电脑上。电脑上的监控程序每 5 分钟录一段视频； surveillance-upload 用开源工具 rclone 把录完的片段复制到我自己的 Google Drive，Surveillance/recordings/ 文件夹下。 这样就算电脑丢了、坏了，录像还在。

它能碰到什么

  • 只申请 drive.file 权限：只能看到、修改它自己上传的文件，看不到 Drive 里的其他任何东西。
  • 只上传录像，从不删除文件，本机和 Drive 上都不删。
  • 数据只在这台电脑和授权账号自己的 Google Drive 之间传输，没有任何服务器或第三方经手。

它不是公开服务，没有网页登录，也不对外提供下载。随时可以在 Google 账号的第三方应用权限页面撤销授权。

English

surveillance-upload is a personal tool that runs on one home computer. It uses the open-source tool rclone to copy finished home surveillance recordings into the owner's own Google Drive, under Surveillance/recordings/.

It requests only the drive.file scope, so it can see and change only the files it uploaded itself. It never deletes files. Data goes only between that computer and the authorizing account's own Google Drive; no server or third party is involved. It is not a public service. Access can be revoked at any time in your Google Account permissions.
