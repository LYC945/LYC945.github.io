隐私政策

surveillance-upload · 生效日期 2026-11-02

访问哪些 Google 数据

只申请一个权限：https://www.googleapis.com/auth/drive.file。 有了它，应用可以在 Google Drive 里创建文件夹、上传文件，并读取和修改它自己创建的文件。 Drive 里的其他文件、邮件、通讯录或任何别的 Google 数据，它都看不到。

怎么使用这些数据

唯一的用途，是把本机监控录像（视频文件）复制到授权账号自己的 Google Drive 里备份， 并查询 Drive 剩余空间，避免把空间占满。不分析、不做画像、不用于广告，也不用于训练任何模型。

数据存在哪里、交给谁

  • 上传的录像存在授权账号自己的 Google Drive 里，归该账号所有。
  • Google 发放的访问令牌只保存在运行这个工具的那台电脑上（rclone 配置文件里），不会发到别处。
  • 开发者不运营任何服务器，不收集、不存储、不转让、不出售任何用户数据，也不与第三方共享。

保留与删除

应用从不删除文件。录像在 Drive 里留多久，由账号所有者自己决定，可以随时在 Drive 里删除。 撤销授权：打开 Google 账号的第三方应用权限页面， 移除 surveillance-upload 即可；撤销后应用立即失去访问权限。

Google API 数据政策

本应用使用从 Google API 获得的信息时，遵守 Google API 服务用户数据政策， 包括其中的"有限使用"（Limited Use）要求。

联系

有问题请发邮件到 Google 授权页面上显示的支持邮箱。

Privacy Policy (English)

Data accessed. The app requests a single scope, https://www.googleapis.com/auth/drive.file. With it the app can create folders and upload files in Google Drive and read or modify only the files it created. It cannot see any other Drive files, email, contacts, or other Google data.

How it is used. Solely to copy local home surveillance recordings (video files) into the authorizing account's own Google Drive as a backup, and to read the Drive's free space so it does not fill it up. Nothing is analysed, profiled, used for advertising, or used to train any model.

Storage and sharing. Uploaded recordings stay in the authorizing account's own Google Drive. The OAuth token is stored only on the computer that runs the tool, in its rclone configuration file. The developer runs no server and does not collect, store, transfer, sell or share any user data with anyone.

Retention and deletion. The app never deletes files. The account owner decides how long recordings stay in Drive and can delete them at any time. Access can be revoked at any time in Google Account permissions.

Google API Services User Data Policy. The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Contact. Email the support address shown on the Google consent screen.
